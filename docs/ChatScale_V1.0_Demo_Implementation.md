# ChatScale V1.0 Demo 差异与实施清单

依据：根目录《ChatScale V1.0 完整产品需求文档（PRD）》，2026-11-04。正式 PRD 保持不变。

## 范围与判定

只验收可见功能、交互、边界和本地数据联动，不把未开发真实后端、数据库、第三方服务列为缺陷。继续使用 vben-prototype/apps/web-ele；根目录 React 项目仅参考。

| 模块 | 已有能力保留 | 需要新增或调整 |
| --- | --- | --- |
| 团队 | 成员、团队增删改查、选择器、头像、官方/Webhook AI | 角色配置及角色关联；授权范围、只读与保护规则；在线和会话联动 |
| 渠道 | 网站小部件、TG、聊天页面、配置分组、独立客户端、草稿预览 | 正式客户端与聊天/客户同源；停用、删除、Bot更换、域名与历史边界 |
| 聊天 | 客户端已有本地消息 | 四栏工作台、六分组、系统事件、未读、接管/转接/结束、历史筛选、权限、媒体及翻译 |
| 客户 | 暂无业务页面 | 列表、筛选、侧栏资料、近期会话、回聊/去聊天、资料共享及脱敏 |
| 聊天与接待 | 暂无业务页面 | 租户会话时限、个人消息提醒、个人收发翻译配置及计时联动 |
| 个人中心 | Vben示例账号菜单 | 本人资料、接待Switch、语言、模拟登录/退出、修改密码与离线改派 |

## 实施顺序

1. 共用角色与权限、会话/客户、账号配置模型；保留成员及渠道 Store。
2. 角色配置及既有团队的角色和访问规则。
3. 聊天与客户，连接渠道、成员、历史和操作反馈。
4. 设置与个人中心，连接在线状态、会话计时和个人偏好。
5. 构建、类型检查、核心业务回归、浏览器视觉及交互自查。

## 规则优先级与缺口

- 渠道篇3.1旧验收条目称删除不改变旧会话状态；采用文首优先级、聊天6.0和X14：手动删除渠道结束其未结束会话，停用不直接结束。
- 会话时限未指定生产固定默认值，Demo初始演示值与正式默认值区分；不擅自补写PRD。
- 真实Webhook协议、鉴权及多设备服务端检测不实现，前端只模拟其可见结果。
- 现有客户端独立 localStorage 消息未接入工作台；这是联动缺口，不能仅添加聊天页面掩盖。

## 验证清单（未完成不得勾选）

- [ ] 默认角色只读；自定义角色创建/编辑/删除、依赖和被引用保护。
- [ ] 新角色可用于新成员；成员可参与对应团队转接与分配。
- [ ] 普通成员只读团队；权限变更立即收回菜单和数据。
- [ ] 首次分配无分配事件；后续改派统一系统事件；待分配不重复记录。
- [ ] 客户首次成功发消息建档；已有活动会话复用；回聊创建空正式人工会话。
- [ ] 下线和权限收回按原团队人工兜底，不回流AI。
- [ ] 改绑渠道只影响新会话；停用禁收发；删除归档；团队删除差异迁移。
- [ ] 客户资料跨页同步；历史无权限脱敏，Web180天正文及摘要不可见。
- [ ] 会话参数、消息通知、翻译、个人资料及语言保存反馈。
- [ ] 团队和渠道已有创建、编辑、预览不回归。
- [ ] 类型检查、构建及浏览器主要流程通过。
