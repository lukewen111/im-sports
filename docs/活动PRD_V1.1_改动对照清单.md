# ChatScale【活动】模块 PRD V1.1 改动对照清单

- 原文档：ChatScale【活动】模块产品需求文档_V1.0
- 修订文档：ChatScale【活动】模块产品需求文档_V1.1
- 修订范围：仅以下五处，其余章节保持原样，不新增功能
- 版本变更：V1.0 → V1.1

## 改动明细

### 1. 活动卡片展示（3.2 活动卡片 · 底部左侧）

| 项 | 内容 |
|---|---|
| 原表述 | 重复频次＋配置的计划时间，并展示活动配置的时区。例如「每天 10:00 · UTC+00:00」。 |
| 新表述 | 重复频次＋配置的计划时间，例如「每天 10:00」。时区仍在创建／编辑活动时配置并随活动保存，卡片不展示时区。 |
| 依据 | 产品原型当前卡片不展示时区；经用户确认保留现状、修订 PRD。时区仍保留在创建／编辑的配置与保存链路中，仅从卡片展示中移除。 |

### 2. 活动名称唯一性（2.1 配置字段 · 活动名称）

| 项 | 内容 |
|---|---|
| 原表述 | 内部活动标识，不作为消息发送给客户；当前租户内名称唯一。 |
| 新表述 | 内部活动标识，不作为消息发送给客户；当前渠道类型内名称唯一，同一渠道类型下不可重名，不同渠道类型之间允许同名。 |
| 依据 | 产品原型实现为「当前渠道类型内唯一」；经用户确认修订 PRD 对齐现有实现，不同渠道类型之间允许同名。 |

### 3. 卡片更多操作位置（3.2 活动卡片 · 更多操作）

| 项 | 内容 |
|---|---|
| 原表述 | 鼠标悬浮在卡片底部时出现更多入口，包含「立即运行」「编辑」「删除」三个选项，按第 4 节的规则控制可用性。 |
| 新表述 | 位于卡片右上、启停开关左侧，鼠标悬浮在卡片上时出现；包含「立即运行」「编辑」「删除」三个选项，按第 4 节的规则控制可用性。 |
| 依据 | 原型交互为「卡片右上、启停开关左侧，悬浮出现」，且为用户明确要求的位置；经确认保留现状、修订 PRD。三项操作内容不变。 |

### 4. 发送结果展示格式（7.2 列表字段 · 发送结果）

| 项 | 内容 |
|---|---|
| 原表述 | 分别展示成功发送和最终发送失败的消息条数，例如「成功 195」「失败 5」。 |
| 新表述 | 按「成功 N / 失败 N」格式展示成功发送和最终发送失败的消息条数，保留斜杠，例如「成功 195 / 失败 5」。 |
| 依据 | 原型实际展示为「成功 N / 失败 N」并保留斜杠；经用户确认在 PRD 中补充该格式要求。 |

### 5. 卡片状态展示（3.2 活动卡片 · 底部右侧）

| 项 | 内容 |
|---|---|
| 原表述 | 当前活动状态：进行中、已暂停或「已过期，不再执行」。 |
| 新表述 | 当前活动状态：进行中、已暂停或「已过期，不再执行」。卡片底部始终只显示活动状态；任务运行中不替换活动状态，也不额外展示「运行中」标识。 |
| 依据 | 用户确认卡片底部始终显示活动状态，运行中不替换活动状态、也不额外展示「运行中」标识。 |

## 说明

- 除上述五处外，V1.1 与 V1.0 正文内容完全一致（仅文档信息的版本号由 V1.0 更新为 V1.1）。
- 本次修订不涉及新增功能、不调整业务规则、不改变统计口径与验收标准。
