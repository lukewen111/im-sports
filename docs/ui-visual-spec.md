# UI 视觉规范（基于两张参考截图）

> 适用范围：`vben-prototype` 的 Element Plus 应用（实际业务目录为 `vben-prototype/apps/web-ele/src`，仓库中不存在 `vben-prototype/src`）。
> 证据来源：
> - `ScreenShot_2026-11-04_144409_923.png`（会话台 Inbox）
> - `ScreenShot_2026-11-04_144432_012.png`（客户列表 Contacts）
> 本文只做视觉分析与落地建议，不包含代码改动。所有尺寸为截图测量 + 换算估算，**误差 ±2px**；无法确认的部分显式标注「推断」。

---

## 0. 结论

这套截面的视觉语言是「**中性灰画布 + 白卡片 + 近黑文字**」，几乎不靠品牌色，而是靠**留白、层级分明的灰度、1px 细描边**建立结构。截图里唯一的高饱和色是极小的状态点（红色计数徽标 #CA0005、进度环蓝、在线绿），大面积色块只有三块低饱和浅色：信息提示浅蓝 #DAEDFF、AI 回复浅紫 #F2F0FE、试用条浅黄 #FEE09B。圆角偏大（卡片 16–20px、控件 8–10px），投影基本为零，分割线极浅（#ECECED）且只做横向。字体是 Inter/SF 一类的现代 grotesque，标题 600 字重、正文 400、元数据 12px 灰，整体密度中等偏松（行高 44–52px）。

与 Vben 现状相比，最大的差异不在组件细节，而在**色彩策略**：现在的应用是「饱和蓝 (#1677ff/#1664ff) + 浅蓝底色 (#edf4ff) + 蓝色气泡/蓝色头像」，而参考截图把「品牌色」几乎让位于「中性灰 + 近黑」，蓝色只作为信息底色使用。

## 1. 视觉解构

### 1.1 整体版式与栅格

截图窗口为 2559×1306 的超宽屏截图。按比例还原到 1440 宽度时，各区块占比约为：

| 区域 | 截图像素 | 占比 | 落地建议（1440 宽） | 说明 |
| --- | --- | --- | --- | --- |
| 顶部试用条 | 高 ≈ 72 | 全宽 | 36–40px | 浅黄底，单行文案 + 右侧按钮 |
| 顶栏（logo / 状态胶囊 / 全局搜索 / 头像） | 高 ≈ 84 | 全宽 | 42–48px | 与画布同色 #F5F5F5，无分割线 |
| 左侧图标栏 | 宽 ≈ 110 | 4% | 44–48px | 竖向图标，选中项为灰色方块 |
| 左侧导航列 | 宽 ≈ 390 | 15% | 196–210px | 分组标题 + 二级项 + 计数 |
| 会话列表卡 | 宽 ≈ 506 | 20% | 250–260px | 白卡片，行高 ≈ 100（≈52px） |
| 会话主区 | 剩余 | — | 自适应 | 白色画布 + 顶部标题栏 + 底部输入卡 |
| 详情面板 | 宽 ≈ 626 | 24% | 300–320px | 白卡片，字段列表 + 分区折叠 |
| 内容卡片间距 | 10–12 | — | 8px | 卡片之间用画布色透出间隙 |
| 卡片内边距 | 40–48 | — | 16–24px | 头部 16–20，正文 20–24 |

关键规则：

- **卡片浮在 #F5F5F5 画布上**，靠 1px 描边 + 8px 间隙分层，不用投影。
- 导航列与图标栏是**同一块 #F5F5F5**，没有自己的卡片，也不与内容区同高（内容卡片上下各留 4–8px）。
- 内容区里的表头、工具栏、列表主体都在**同一张白卡片内部**，用 1px 横线分区（如 Contacts 页的标题栏下划线）。
- 右侧详情面板内部同样用横线切分「基本信息 / Qualification / Customer context / Chat info / Chat tags」，每段上下留白 20–24px。

用色规则（从截图归纳）：

1. 页面**没有**「品牌主色按钮」；唯一的主行动按钮是侧栏顶部的**纯黑方块「+」**，其余主按钮需要推断（推断为黑底白字）。
2. 蓝色只用于「信息提示底色 + 浅色标签」，不用于文字链接、不用于气泡、不用于选中态。
3. 颜色永远以「浅底 + 深字」成对出现（如 `#DAEDFF` 底 + 深蓝字，`#FEE09B` 底 + 近黑字）。
4. 状态一律用**小圆点**表达（country 前的红点、在线绿点），不用彩色图标或彩色整行。

### 1.4 字体层级

字体族：几何感 grotesque，双层 a、字腔开阔，接近 **Inter / SF Pro**（推断；也可能是 Söhne 一类商用字体）。字距正常（无负字距），行高 1.45–1.55。

| 用途 | 字号 | 字重 | 颜色 |
| --- | --- | --- | --- |
| 面板标题（Inbox / Contacts / Sample Chat） | 17–18 | 600 | #131317 |
| 二级区块标题（Chats / Qualification / Chat info） | 14–15 | 600 | #131317 |
| 导航项、正文、表格单元格 | 13–14 | 400–500 | #131317 |
| 表格表头 | 12–13 | 500 | #62626D |
| 字段标签（Team / Assignee / Chat ID） | 13 | 400 | #707072 |
| 元数据（时间、条数、提示） | 11–12 | 400 | #8C8C8E |
| 导航分组标题 | 13 | 600 | #131317 |
| 计数 / 角标 | 12 | 500 | #131317 或白字 |

#### 1.5.1 蓝色 accent 的使用边界

- 新增 token `--ui-accent: #003fa4`，只用于：描边按钮的边框与文字、链接、输入框/可交互元素的聚焦环、少量选中强调。
- 不用于：主按钮底色（保持 `#131317`）、侧栏选中态（保持灰胶囊）、卡片描边、表格表头、头像底色。
- `--el-color-primary` 保持近黑，不改为蓝色，避免 Element Plus 主色阶整体变蓝。

#### 1.5.2 按钮实现

- 公共类 `.ui-btn-outline` 同时支持原生 `<button>` 与 `<el-button>`。
- 尺寸跟随控件：高 32–36、圆角 8、水平内边距 12–14。
- 图标按钮仍用 `QIcon` 线性图标，不混用其他图标风格与彩色 emoji。

#### 1.5.3 描边按钮的适用范围与接入状态

适用场景（凡是**看起来像可点击文字**的次级操作，一律改用蓝描边按钮 `.ui-btn-outline`）：

- 查看更多、加载更多、展开全部
- 复制、复制链接、复制代码
- 回聊、去聊天、打开聊天页面
- 编辑、重命名、修改
- 清空筛选、清空搜索、重置
- 重试、重新加载

不适用：

- 主行动按钮：保持近黑实底白字（`#131317`），不用蓝描边。
- 危险操作：保持红字/红描边（`#CA0005`）。
- 纯跳转文字链接：用 `.ui-link`（蓝色文字 + hover 下划线），不加描边。

接入状态：本阶段只落地 token 与公共类，**不逐页替换既有的文字型操作**——`inbox`、`customers` 等页面正由并行任务重写，直接替换会产生冲突。该规范由后续页面任务在新版结构中逐页接入；未接入前不得在页面内另写一套蓝色文字按钮。

### 1.6 图标

- 线性、**1.5–2px 描边**、圆角端点、24px 画布内 18px 视区；工具栏用 20px。
- 颜色只有两种：`#131317`（当前可操作）与 `#707072`（辅助/未选中），不做彩色图标。
- 品牌标是**实心黑**的唯一例外；AI 入口用黑底 + 黄色星形。
- 所有图标与文字基线对齐，图标与文字间距 8px；导航项图标区固定 20px 宽。

### 2.3 能一次生效 vs 必须组件级

**全局一次生效**（改 token / preferences 即可）：
1. 主色与 EP 色阶（`colorPrimary`）
2. 画布、卡片、描边灰阶
3. 文字三级灰
4. 控件圆角与高度、字号、字体族
5. Element Plus 表格的表头底色/文字/边框/hover
6. EP 输入框边界色、按钮禁用态
7. Vben 菜单项的颜色体系
8. 侧栏底色（需删掉 `im-support.css` 里的 `#dfecff` 强制值，否则 token 被覆盖）

**必须组件级改**（token 覆盖不到）：
1. **页面构图**：`inbox` 的四栏是硬编码 grid + `border-right:1px`，没有「卡片浮在画布上」的结构，需要改成「画布 + 3 张独立白卡片」。
2. **卡片圆角与内边距**：`customers` 的 10px 圆角写死在 `.customer-page section` 里；`channels` 有 18px 卡片和 4px 控件混用。
3. **聊天气泡**：颜色/圆角/时间位置写死在 `.message span`，且 AI 用了实心蓝 `#1677ff`。
4. **输入区（composer）**：灰底卡片、内嵌工具条、禁用态 Send 都属于自定义结构。
5. **分段控件 / 可折叠分区**：右侧详情面板与表格页头都需自绘。
6. **标签 chips、计数徽标、状态点**：目前是 `#edf4ff` + 蓝字，需换成 `#DAEDFF` + 深蓝字 / 灰胶囊。
7. **侧栏选中态形状**：Vben 菜单是整行 72% 透明白，参考图是可缩进的灰色胶囊（左右各留 8px）。
8. **表格行高与列间距**：EP 默认行高与参考的 44–52 差距较大，需要显式设置。
9. **空态 / 加载态**：全站尚未统一（各页写法不一）。

## 6. 标签与徽标

全站标签按「四档层级」表达主次。样式定义在 [`apps/web-ele/src/styles/ui-tags.css`](../vben-prototype/apps/web-ele/src/styles/ui-tags.css)，由 `bootstrap.ts` 在 `ui-components.css` 之后引入；页面只写 class，不再各自定义颜色。

### 6.1 四档适用场景

| 档位 | 用途 | 典型文案 | 视觉 |
| --- | --- | --- | --- |
| **solid** | 最高级：身份 / 归属 | Owner、系统默认、官方接入 | 近黑 `#131317` 实底 + 白字，胶囊 |
| **outline** | 次级：类型 / 角色 | AI 成员、管理员、渠道类型 | 白底 + 1px 同色系描边 + 同色文字 |
| **soft** | 提示类 | 待分配、未启用、默认、译文 | 浅色底 + 同色文字，无描边 |
| **neutral** | 普通状态 / 中性信息 | 人类成员、自定义角色、渠道名 | 浅灰底 `#EEEEEF` + 次级灰字 `#62626D` |

### 6.2 尺寸（只有两档）

| 档位 | 高度 | 字号 | 左右内边距 | 圆角 | class |
| --- | --- | --- | --- | --- | --- |
| 默认 | 24 | 12 | 8 | 12 | `.ui-tag` |
| 小号 | 20 | 11 | 6 | 10 | `.ui-tag.is-sm` |

- 圆角 12 在 24 高度下即为胶囊，所以不再额外写 `border-radius: 999px`。
- 可选前置状态点：`<i class="ui-tag__dot"></i>`，6px 圆点，默认取文字色 `currentcolor`；可叠加 `.is-success` / `.is-warning` / `.is-danger` / `.is-muted` 指定颜色，用于「在线 / 离线 / 接待中」。
- 尺寸 token：`--ui-tag-height`、`--ui-tag-padding-x`、`--ui-tag-radius`、`--ui-tag-font-size`。

### 6.3 颜色对照

| 语义 | class | soft（默认） | outline |
| --- | --- | --- | --- |
| 信息蓝 | `.is-info` | 底 `#DAEDFF` / 字 `#0B4A82` | 描边与字 `#003FA4`（品牌蓝不做填充） |
| AI 紫 | `.is-ai` | 底 `#F2F0FE` / 字 `#7E3D8C` | 描边与字 `#7E3D8C` |
| 提醒黄 | `.is-warn` | 底 `#FEE09B` / 字 `#7A5200` | 描边 `#D0810B` / 字 `#7A5200` |
| 危险红 | `.is-danger` | 底 `#FDE7E7` / 字 `#CA0005` | 描边与字 `#CA0005` |
| 成功绿 | `.is-success` | 底 `#E4F6EC` / 字 `#187747` | 描边 `#1E9E5B` / 字 `#187747` |
| 中性 | `.is-neutral` / `.is-soft` | 底 `#EEEEEF` / 字 `#62626D` | 描边 `#C9C9CD` / 字 `#131317` |

组合写法：`<span class="ui-tag is-soft is-info">待分配</span>`；只写语义类（如 `is-info`）等价于 soft，便于老代码平滑迁移。`is-sm` 可与任意组合叠加。

### 6.4 Element Plus `ElTag` 映射

`ui-tags.css` 用双类选择器（`.el-tag.el-tag`、`.el-tag.el-tag--success` 等）接管 EP 默认样式，使其与自研标签同观感：

- 默认（无 `type`）与 `type="primary"` / `type="info"` → neutral：`#EEEEEF` 底、`#62626D` 字、无描边、高 24 / 字 12 / 圆角 12；
- `type="success"` / `"warning"` / `"danger"` → 对应语义的 soft 档（浅底 + 同色字 + 无描边）；
- `size="small"` → 小号（20 / 11 / 6 / 10）；
- `round` 沿用胶囊（12 与 999 在 24 高度下视觉等价，统一收敛到 12）；
- 需要 solid 时用 `.el-tag.ui-tag.is-solid` 叠加，通过 `--el-tag-*` 变量改色；
- 关闭图标 hover 改为近黑文字，不再使用 EP 的彩色实底。

### 6.5 使用禁忌

1. **solid 一屏不超过 1–2 个**。逐行重复出现的标签（角色列表的「系统默认」）降级为 soft，避免整屏黑块。
2. **不要用红底做普通状态**。`#CA0005` 只给危险、失败、即将失效；`#FDE7E7` 浅红底也只能表达这类含义。
3. **不要用品牌蓝 `#003FA4` 做填充**。蓝色只出现在 outline 的描边与文字、链接、聚焦环。
4. **不要用标签代替状态点**。在线 / 离线这类瞬时状态优先用 `.ui-tag__dot` 或 `.ui-status`，标签只承载稳定属性。
5. **不要给标签加投影或渐变**，也不要自造第二套圆角（非 12 / 10）。
6. **同一行内标签不超过 2 个**，多值场景改为逗号分隔的文字列表。
7. **文案保持 2–6 个字**，超长名称截断由外层容器负责，标签本身 `white-space: nowrap`。
